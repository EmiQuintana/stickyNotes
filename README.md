# Sticky Notes

Desktop web app built with TypeScript and React. There is no component library: UI is written in the project.

Target environment:

- Desktop, minimum resolution 1024x768
- Latest Google Chrome (Windows and Mac), Mozilla Firefox, and Microsoft Edge

## Prerequisites

- Node.js 22 or later
- npm 10 or later

## Run locally

```bash
npm install
npm run dev
```

Vite prints a local URL. Open it in a desktop browser.

## Production build

```bash
npm run build
npm run preview
```

`npm run build` type-checks the project and writes the static files to `dist/`.

## Scripts

| Script | Purpose |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Run Oxlint |
